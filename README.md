# 🏥 Healthcare Analytics Dashboard

Dashboard interaktif penerapan Data Mining pada data kesehatan rumah sakit.

## Fitur
- 📈 **Regresi** — Prediksi biaya tagihan pasien (Linear Regression)
- 🔬 **Klasifikasi** — Prediksi hasil tes pasien (Decision Tree)
- 🔵 **Clustering** — Segmentasi kelompok pasien (K-Means)
